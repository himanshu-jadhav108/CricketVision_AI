# Dataset

CricketVision AI was trained on pose-derived features extracted from cricket batting imagery. The runtime repository ships processed feature tables for transparency; raw video archives are excluded due to size and licensing.

## Classes

Six professional shot types are trained and supported in the production model:

- Cover Drive (`cover_drive`)
- Pull Shot (`pull_shot`)
- Cut Shot (`cut_shot`)
- Sweep Shot (`sweep_shot`)
- Scoop Shot (`scoop_shot`)
- Leg Glance (`leg_glance_shot`)

*Excluded from training:* `straight_drive` was excluded due to an insufficient sample count (~345 sequences vs. 1000+ for the top classes).

## Sources

- Public cricket coaching datasets (e.g. Kaggle collections such as `awais69/cricket-coaching-dataset`)
- Curated batting frame samples collected during development

## Processed Artifacts

| [`data/features/features_all.csv`](../data/features/features_all.csv) | Full extracted feature set |

Each row represents one frame's biomechanical feature vector plus metadata (label, source path).

## Feature Schema

Features are generated by [`features/feature_builder.py`](../features/feature_builder.py) and include:

- 3D joint angles (elbow, shoulder, knee, hip)
- Trunk lean and normalised limb distances
- Z-depth wrist reach and shoulder tilt
- Bat-vector orientation proxies
- Optional temporal velocity (when a previous frame is available)

The canonical feature name list is exported as `FEATURE_NAMES` in the feature builder module.

## Splitting Strategy

**Critical:** splits must be grouped by video or session ID. Frame-level random splits cause data leakage because consecutive frames are nearly identical. Production evaluation uses video-grouped holdout sets.

## Class Balance

The dataset exhibits natural imbalance — common shots (cover drive, pull) outnumber rare shots (scoop, cut). Training applies class weighting to mitigate bias.

## Limitations

- Performance depends on MediaPipe detecting a full batting pose.
- Side-on and 45° camera angles work best; extreme zoom or occlusion degrades quality.
- Low-light and motion-blur frames reduce landmark confidence.

## Known Limitations

- **Weak-Class Sample Imbalance:** `cut_shot` (F1 0.74, ~390 training sequences) and `scoop_shot` (F1 0.85 but precision only 0.79, ~485 sequences) are the weakest-performing classes, correlated with having the fewest training sequences among the 6 trained classes. Recommend collecting additional `cut_shot` and `scoop_shot` samples as the highest-leverage next step before attempting any architecture change.
